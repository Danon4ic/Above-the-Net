# Звук Above the Net

Музыка ведёт главное меню. В матче переходы обозначают короткие джинглы, а мяч, шаги и свисток остаются слышны поверх трибун. Дубли касаний отличаются атакой и длиной хвоста. На выбор влияют техника, импульс контакта, покрытие и предыдущий дубль. В повторе сохраняются время, позиция и конкретный дубль касания. Уровень и панорама пересчитываются для камеры повтора.

| Событие | Имя банка и число дублей | Звуковая деталь |
| --- | --- | --- |
| Нижняя подача, планер, силовая, планер в прыжке, топспин в прыжке | `serve_underhand`, `serve_float`, `serve_power`, `serve_jump_float`, `serve_jump_topspin` · по 3 | Нижняя подача мягче, у планера короткий щелчок, у силовой и топспина плотнее низ и длиннее хвост |
| Подброс | `serve_toss` · 1 | Короткое тихое касание перед подачей |
| Приём снизу, жёсткий приём | `forearm_pass` · 4, `forearm_hard` · 3 | Жёсткий банк включается при большом изменении скорости мяча |
| Передача сверху, передача одной рукой | `overhead_set` · 4 | Мягкая атака с коротким хвостом |
| Скидка, накат, силовой удар | `spike_soft` · 3, `spike_roll` · 3, `spike_hard` · 4 | Лёгкий щелчок, протяжное касание, резкий удар с плотным низом |
| Блок | `block` · 3 | Компактное жёсткое касание |
| Рыбка, сейв одной рукой | `dig`, `dig_one_arm` · по 3 | Глухой удар при рыбке, более сухое касание одной рукой |
| Отскок от площадки | `ball_floor`, `ball_sand`, `ball_roof` · по 2 | Уровень и высота зависят от скорости столкновения |
| Сетка, лента, антенна или стойка, стена, корпус | `ball_net`, `ball_tape` (2), `ball_metal`, `ball_wall`, `ball_body` | Материал определяет тембр |
| Постановка стопы | `footstep`, `footstep_wood`, `footstep_sand`, `footstep_concrete` · по 6 | Фаза шага общая с анимацией. Приставные шаги тише. Каждый игрок перебирает дубли без соседних повторов |
| Торможение, смена направления и прыжок с разбега | `plant`, `plant_wood`, `plant_sand`, `plant_roof` · по 3 | Постановка нагруженной стопы и трение сведены в один звук. Обычный шаг в этот момент заменяется акцентом |
| Толчок, приземление, падение и скольжение | `jump_takeoff`, `body_fall`, `landing`, `landing_sand`, `landing_roof`, `dive_slide`, `dive_slide_sand`, `dive_slide_roof` · по 2 для посадки и скольжения | События привязаны к отрыву от пола и контакту с ним. Песок и крыша используют свои банки |
| Усилие, подсказка принимающего | `grunt`, `team_receive_cue` · по 2 | Усилие слышно на части прыжков и ударов. Подсказка звучит со стороны назначенного партнёра при доступном мяче, максимум раз за розыгрыш |
| Выбор действия, переход в режим, начало повтора | `action_change` (2), `mode_change` (2), `replay_start` | Оригинальные короткие музыкальные фразы |
| Подача по свистку, конец очка, конец партии, тайм-аут | `whistle_short`, `whistle_long`, `point_chime`, `set_horn`, `timeout_buzzer` | Свисток сразу освобождает место в миксе. Реакция трибун приходит с задержкой |
| Арены | `crowd_ambient`, `crowd_beach`, `crowd_gym`, `crowd_palace`, `crowd_rooftop` | Пляж почти без отражений, крыша с тихим отражением, школьный зал с быстрым, дворец спорта с более поздним |
| Реакции публики | `crowd_cheer`, `crowd_groan`, `crowd_ooh`, `crowd_claps`, `crowd_chant` | Перед подачей на сетболе фон падает до 30% от обычного. Сейвы вызывают короткую реакцию, результат очка меняет её характер |
| Главное меню | `menu_music` | Музыка затухает при входе в матч |

Записи до обработки сохранены в [архиве исходников](source-recordings.zip). Обработанные дубли и зацикленные подложки находятся в [ресурсах игры](../../core/src/main/resources/audio/). [Авторы и лицензии](../../core/src/main/resources/audio/CREDITS.md) указаны рядом с ресурсами. [Скрипт микширования](mix_variations.py) собирает новые варианты из существующих WAV и создаёт джинглы и подсказки. Для повторного рендера из корня проекта запусти `python art/audio/mix_variations.py` с NumPy, SciPy и FFmpeg.

[Скрипт шагов и опор](mix_footsteps.py) сводит их из архива исходников. Если нужно заново собрать всё аудио, сначала запусти `python art/audio/mix_footsteps.py`, затем основной скрипт вариаций.
