# Above the Net

3D-симулятор классического волейбола 6×6 на Java 25 + LibGDX 1.13.1 (LWJGL3, OpenGL).
Разработка идёт поэтапно; после каждого этапа проект собирается, тестируется и запускается.

## Требования
- JDK 25 (проверено на Temurin 25.0.4)
- Gradle ставить не нужно: в проекте есть Gradle Wrapper (`gradlew`, `gradlew.bat`), он сам скачает Gradle 9.8.2
- Windows 10/11 или Linux с поддержкой OpenGL 2.0+

## Запуск как приложения (Windows)
```bash
./gradlew :lwjgl3:packageApp
```
Результат — папка `lwjgl3/build/app/VolleyballSimulator3D/` с файлом **`VolleyballSimulator3D.exe`** и встроенной
урезанной Java (~90 МБ). Устанавливать Java на компьютер игрока не нужно: папку можно скопировать куда угодно и
запускать `.exe` двойным щелчком (можно создать ярлык на рабочем столе).

```bash
./gradlew :lwjgl3:packageZip         # тот же образ в zip: lwjgl3/build/distributions/VolleyballSimulator3D-<версия>-windows.zip
./gradlew :lwjgl3:packageInstaller   # установщик .exe с ярлыками в меню «Пуск» (нужен WiX Toolset в PATH)
./gradlew :lwjgl3:packageInstaller -PinstallerType=msi
```
На Linux те же задачи собирают исполняемый файл `bin/VolleyballSimulator3D` и пакет `.deb`.

## Сборка и запуск для разработки
Из корня проекта (на Windows вместо `./gradlew` — `gradlew.bat`):

```bash
./gradlew build                 # компиляция + все тесты
./gradlew test                  # только тесты
./gradlew :lwjgl3:run           # запуск игры

./gradlew :lwjgl3:installDist   # дистрибутив со скриптом запуска
lwjgl3\build\install\lwjgl3\bin\lwjgl3.bat     # Windows
lwjgl3/build/install/lwjgl3/bin/lwjgl3         # Linux

./gradlew :lwjgl3:dist          # один исполняемый jar со всеми зависимостями
java --enable-native-access=ALL-UNNAMED -jar lwjgl3/build/libs/VolleyballSimulator3D-<версия>.jar
```
Версия игры задаётся в `gradle.properties` (`gameVersion`).

Настройки хранятся в `~/.volleyball-sim/settings.json` (на Windows — `C:\Users\<имя>\.volleyball-sim\`).
Повреждённый файл не ломает запуск: игра берёт резервную копию `settings.json.bak` или значения по умолчанию,
а испорченный файл сохраняет как `settings.json.corrupt`. Логи падений пишутся в `~/.volleyball-sim/logs/`.

## Главное меню
Игра открывается титульным экраном: за меню в настоящем 3D-зале идёт показательный матч двух профессиональных
команд ИИ, камера медленно облетает площадку, играет музыка меню и шумит зал. Пункты:
**Quick match** (быстрый матч: роль с руководством, уровень ИИ, один или двое игроков, формат, система,
**своя команда и соперник** — любой из 8 клубов или Random),
**Training** (упражнения), **Two players** (вдвоём на одном ПК), **Settings** (громкости, полный экран, мышь,
поле зрения, площадка, свет, сетка — меняются стрелками, сохраняются сразу), **Controls**, **Exit**;
Career, Tournament и Online отмечены «SOON». Управление — стрелки и Enter или мышь (правый щелчок — шаг назад
по значению). В игре **Esc** открывает паузу: продолжить, начать заново, руководство роли, управление,
главное меню, выход.

Интерфейс набран шрифтом **Montserrat** (лицензия SIL OFL, файлы в `core/src/main/resources/fonts/`), который
FreeType рисует чётко в любом размере; в шрифт включена кириллица.

## Роли
Перед матчем выбирается роль: **доигровщик** (outside hitter), **связующий** (setter), **диагональный**
(opposite), **центральный блокирующий** (middle blocker) или **либеро**. Для каждой — краткое руководство
(в меню выбора, в F1 и в паузе), и компьютерные игроки действуют по нему же:

| Роль | Приём подачи | Атака | Блок | Защита |
|---|---|---|---|---|
| Доигровщик | основной принимающий, своя полоса | 4-я зона (высокая на край), пайп из 6-й | левый край | 5-я зона |
| Связующий | не принимает; на подаче соперника выбегает к сетке | вторая передача; в передней линии — откидка | правый край | 1-я зона |
| Диагональный | не принимает | 2-я зона (передача назад) | правый край | 1-я зона |
| Центральный | не принимает | квик в 3-й зоне, отвлекающий прыжок | в каждом блоке | в задней линии его заменяет либеро |
| Либеро | ведёт приём | не атакует; вторым касанием пасует снизу | не блокирует | 6-я зона, нырки |

После подачи все переходят на позиции своего амплуа («переход»), до подачи — стоят по расстановке. Либеро
выходит вместо центрального задней линии (кроме подачи этого центрального) и уходит, когда центральный
переходит в переднюю линию; игрок на скамейке ждёт у скамейки. Если ваш игрок уходит на скамейку, вы
управляете тем, кто его заменил (центральный ↔ либеро), и получаете своего обратно, когда он возвращается.

Мяч, опускающийся в 2 м от человека (или в его полосе приёма), ИИ оставляет человеку; вмешивается, только если
человек явно не успевает, а компьютерный игрок успевает.

## Управление
| Клавиша | Действие |
|---|---|
| W A S D | движение относительно камеры («вперёд» — от камеры); игрок разворачивается и бежит в сторону движения, без клавиш — поворачивается к мячу (или к сетке) |
| Shift / Ctrl | ускорение / низкая стойка: приставной шаг лицом к мячу, без разворота |
| Пробел | прыжок при отпускании; чем дольше удерживать (до 0,45 с), тем выше: от 70 до 105 % высоты. Раннее нажатие буферизуется на 0,15 с |
| **ЛКМ** | игра мячом по ситуации: подброс и удар на подаче, приём снизу, пас сверху на втором касании, атака в прыжке |
| **ПКМ** | приём/пас сверху на земле, скидка в прыжке |
| **Ctrl + ЛКМ** | нырок в сторону движения (грудью вперёд); вбок из низкой стойки — падение с перекатом; после — время на подъём |
| Блок | прыжок у сетки, когда атакует соперник: руки блокируют сами; важны тайминг и место |
| Мышь | точка прицеливания на полу (голубое кольцо) для подачи, атаки и перевода |
| 1–9 | выбор на панели внизу экрана: тип подачи / передача (с номером нападающего, которому она пойдёт; затемнённые — нет нападающего в зоне) / удар (сильный, резаный, накат, скидка, в блок-аут, обманный — замах как для сильного, а мяч мягко за блок, по верху блока — в кончики пальцев и далеко) / блок по линии или диагонали. Мяч, до которого не дотянуться двумя руками, на втором касании передаётся одной рукой — дальше, но неточнее |
| 0 | «Auto»: передачу или удар выбирает игра по ситуации — приём, блок, свободные зоны (рекомендованный вариант отмечен голубой точкой) |
| Q / E | листать те же варианты (подающий выбирает заранее — между розыгрышами и пока мяч в руках) |
| M | меню: упражнения (подача, приём, передача, атака, блок, защита, свободный режим) и **быстрый матч** |
| M, затем D / P / O / Y | настройки матча: уровень ИИ (новичок / средний / профессионал) / игроки (1, двое друг против друга, двое за одну команду) / ваша роль / расстановка 5–1, 4–2, 6–2 |
| Esc | пауза: продолжить, заново, руководство роли, управление, главное меню, выход |
| B | скамейка: замены (6 за партию; игрок старта возвращается только на своё место) |
| H | подробности в HUD: скорость и вращение мяча, ротации, касания, FPS |
| I | взгляд ИИ: что делает каждый компьютерный игрок и его шанс успеть к мячу |
| N | звук вкл/выкл |
| − / = | общая громкость (громкость эффектов, зрителей и музыки — в `settings.json`) |
| F5 F6 F7 F8 F9 | быстрый выбор: подача, приём, передача, атака, свободный режим |
| F10 | демо-режим: игрок выполняет упражнение сам |
| R | начать повтор заново (в свободном режиме — убрать мяч) |
| 1–8 | лаборатория мяча (в свободном режиме F9) |
| Tab | сменить игрока (в свободном режиме и в матче — в пределах своей команды) |
| T | показать прогноз траектории точками |
| C | следующая камера |
| Средняя кнопка + мышь | вращение камеры; в режиме от третьего лица — вокруг своего игрока (камера следует за ним) |
| Колесо | приближение / дистанция камеры до игрока |

| F2 / F3 / F4 | тема площадки / освещение / высота сетки |
| F12 | качество графики: Low / Medium / High / Ultra (карты теней, отражения, свет площадки) |
| J | показать/скрыть подсказки клавиш в углу (в начале матча видны несколько секунд, затем сворачиваются в «J Keys · F1 Help») |
| F1 | управление и подсказки (игра на паузе): список тем слева (ваша роль, движение, мяч, удары и пасы, матч, тактика, тренировки, камера, звук и графика, второй игрок), клавиши выбранной темы справа; ↑ ↓ / W S или мышь — выбор темы |
| Esc | закрыть меню / выход из игры |
| F11 или Alt+Enter | полноэкранный режим вкл/выкл (запоминается до следующего запуска) |

Как работает касание: нажатие «заявляет» действие на 0,4 с (в прыжке — на 0,3 с), а контакт происходит,
когда мяч ближе всего к идеальной точке для выбранной техники (руки снизу у пояса, пальцы над лбом, рука в
верхней точке). Слишком раннее нажатие сгорает, позднее или неточная позиция дают плохой контакт.
Качество контакта, характеристики игрока и скорость летящего мяча определяют точность; при приёме и
передаче показывается оценка Perfect / Good / Limited / Emergency.

Второй игрок (матч на двоих на одном ПК) играет без мыши:

| Клавиша | Действие |
|---|---|
| Стрелки | движение (относительно камеры) |
| Правый Ctrl | прыжок (так же заряжается удержанием) |
| Правый Shift / `,` | ускорение / низкая стойка |
| `/` | игра мячом (как ЛКМ); `,` + `/` — нырок |
| `.` | пас сверху / скидка (как ПКМ) |
| `[` / `]` | вариант действия |
| `'` | сменить игрока своей команды |
| Прицел | подачи и атаки направляются стрелками, зажатыми в момент удара: в сторону — линия/диагональ, к сетке/от сетки — коротко/глубоко; без стрелок — в середину площадки |

Все действия переназначаются в `settings.json` (разделы `keyBindings` и `keyBindingsPlayer2`, например
`"JUMP": "J"`, `"PRIMARY_ACTION": "Mouse Left"`). Экран настройки клавиш появится вместе с меню.

Параметры запуска: `VolleyballSimulator3D.exe --drill=attack --autoplay`
(`--drill=serve|receive|set|attack|block|defense|free|match`, `--autoplay` — сразу демо-режим (в матче — компьютер играет за всех),
`--difficulty=beginner|intermediate|pro` — уровень ИИ, `--players=single|versus|coop` — один или двое игроков,
`--role=outside|setter|opposite|middle|libero` — роль в матче,
`--home=` / `--away=` — клубы матча (`wolves`, `sharks`, `titans`, `falcons`, `storm`, `dragons`, `bears`, `comets`
или `random`); без параметров игра открывает главное меню,
`--seed=<число>` — зерно случайности матча или упражнения: с тем же зерном и теми же действиями розыгрыши
повторяются (зерно каждой сессии пишется в лог как `Match: seed …`),
`--pose-gallery` — служебная галерея поз игроков для проверки моделей и анимаций).

## Система координат
Метры. X — вдоль площадки, сетка в плоскости `x = 0`, хозяева на `x < 0`, гости на `x > 0`.
Y — вверх, пол на `y = 0`. Z — поперёк площадки, боковые линии на `z = ±4,5`.
